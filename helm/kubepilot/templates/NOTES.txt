KubePilot {{ .Chart.AppVersion }} is installed in namespace {{ .Release.Namespace }}.

1. Reach the UI
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else if .Values.frontend.enabled }}
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "kubepilot.frontendFullname" . }} 3000:{{ .Values.frontend.service.port }}
  # then open http://localhost:3000
{{- else }}
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "kubepilot.backendFullname" . }} 8080:{{ .Values.service.port }}
{{- end }}

2. Sign in
{{- if .Values.admin.email }}
  Username: {{ .Values.admin.email }}
{{- if .Values.admin.password }}
  Password: the value you passed in admin.password
{{- else }}
  Password: generated on first start — read it from the logs:
    kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "kubepilot.backendFullname" . }} | grep -A 5 "First-Run Setup"
{{- end }}
{{- else }}
  No admin was pre-configured: open the UI and complete the first-run setup screen.
{{- end }}

3. Storage
{{- if eq (include "kubepilot.storageDriver" .) "postgres" }}
  PostgreSQL at {{ .Values.externalPostgresql.host }}:{{ .Values.externalPostgresql.port }}/{{ .Values.externalPostgresql.database }}
{{- else if .Values.persistence.enabled }}
  SQLite on PVC {{ include "kubepilot.pvcName" . }} ({{ .Values.persistence.size }}).
  The PVC is kept on `helm uninstall` — delete it explicitly to wipe the data.
{{- else }}
  WARNING: SQLite on an emptyDir. All data is lost when the pod restarts.
  Set persistence.enabled=true for anything but a throwaway install.
{{- end }}

{{- if not .Values.rbac.nodeMetrics }}

4. Node metrics are disabled (rbac.nodeMetrics=false): the CPU/RAM/disk panels
   will stay empty. They need `get` on nodes/proxy to read each kubelet's
   Summary API.
{{- end }}

{{- if .Values.integrationToken.create }}

Cluster integration token (to register this cluster from another instance):
  kubectl get secret -n {{ .Release.Namespace }} {{ include "kubepilot.fullname" . }}-integration-token -o jsonpath='{.data.token}' | base64 -d
{{- end }}
